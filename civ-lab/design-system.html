06.动效 · 3 档时长 + 3 种缓动

默认所有过渡都用 --ease-default。弹性反馈用 --ease-bounce，角色走路用 --ease-walk。

TokenValue用途
--t-fast150mshover 反馈、按钮按下
--t-base250ms默认过渡、卡片浮起
--t-slow400msmodal 入场、内容切换
--ease-defaultcubic-bezier(.4,0,.2,1)默认所有过渡
--ease-bouncecubic-bezier(.34,1.56,.64,1)弹性入场（hotspot pop）
--ease-walkcubic-bezier(.34,1.2,.5,1)角色 1.5s 走位

14.知识库 Schema

每个 P 节点（PH01/PH02/...）必填的 11 个字段。A 级博物馆/Nature 来源，B 级 DK / NatGeo Kids 语言，C 级课程设计。

{
  "node_id":         "P01_homo_sapiens_origin",
  "title":           "30万年前：现代人类的出现",
  "time_range":      "约30万年前-5万年前",
  "core_question":   "什么是现代人类？我们从哪里来？",
  "fact_base":       [],  // A级事实, 每条带具体论文/博物馆出处
  "child_explanation": [],  // B级 (DK / NatGeo Kids) 儿童语言
  "map_points":      [],  // 实际遗址点带经纬度
  "evidence_objects":[],  // 真实馆藏 (含编号、展馆)
  "key_events":      [],  // 时间线
  "key_people_or_groups": [],  // 学者/古人群
  "civilization_connection": [],  // 与文明的因果链
  "common_misconceptions":   [],  // 反幻觉常识
  "ai_tasks":        [],  // 现成的 AI 任务题
  "anti_hallucination_rules":[],  // AI 不能说什么
  "sources":         []   // A/B 级来源带 URL
}
来源分级 什么算 A/B/C/D
级别来源用途
A 级博物馆、Nature、Britannica、UNESCO、大学教材事实底板
B 级DK、National Geographic Kids、博物馆儿童教育儿童语言
C 级自己的课程模型、AI 任务、作品集任务教学转化
D 级短视频、公众号、未标注网页、AI 编造的细节❌ 禁止依赖

15.无障碍 · 朗读 · 演示

每个知识卡有 🔊 朗读按钮（Web Speech API 中文）。演示模式可隐藏所有设置入口。

  • 语音朗读 · 每个详情卡右上角 🔊 按钮，自动 strip HTML，播放时变绿色脉冲，再点暂停
  • 键盘导航 · 所有按钮支持 Tab + Enter，:focus-visible 显示金色聚焦环
  • 触摸目标 · 移动端最小 44×44px，加 tap-highlight 反馈
  • 对比度 · 主文字 #2C1A08 on #F2E4C4 = 11.2:1（WCAG AAA）
  • 演示模式 · 普通 URL 隐藏所有 ⚙ 设置按钮；?admin=1 显示
  • 课程锁定 · DEMO_UNLOCKED_LESSONS 数组控制可访问课程，锁定显示 🔒 + 灰色斜纹
