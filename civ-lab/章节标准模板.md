## 第一部分 · 设计理念（为什么这样做）

1. **三层下钻，不是平铺**：宇宙时间长河（总览）→ 文明深度页（教科书）→ 人物/事件放射宇宙（细节）。每一层都能返回上一层。
2. **数据驱动**：一份 `CIV_META` 元数据 + 几张映射表，自动生成时间轴、章节、对比、总汇、人物/事件页。新章节 = 填数据，页面自动成形。
3. **一眼看懂时间**：横轴=真实年代，每个文明一条"存续光条"(淡→浓→淡 = 崛起→巅峰→衰落)，按地理带分行，悬浮即见"同期共存文明"。
4. **教科书级可信**：A/B/C 来源分级、考古证据、常见误解（反幻觉）、遗址标注"今天在哪"，培养批判性思维。
5. **正式产品感**：去掉一切原型/指令式文字；字大、对比强、留白足；图标必须贴合内容、绝不出戏。
6. **面向 10–15 岁**：语言生动但不幼稚（成人也愿读），每个知识点可朗读、可问 AI、可查双语维基。

## 第四部分 · 三个页面的排版规范（精确参数）

### A. 总览页 explorer（宇宙时间长河）
- SVG `viewBox="0 0 1600 900"` `preserveAspectRatio="xMidYMid meet"`；`PAD_L=210, PAD_R=250, PAD_TOP=110, PAD_BOT=80`。
- 时间轴：`Y0,Y1`=本章起止年(留约 50 年余量)；`yearToX()` 线性映射；网格竖线+年代标签 `for(y=Y0取整;y<=末;y+=100)`。
- **地理带(REGIONS)**：每带一组 `civs`，横向分行。每个 civ `{id,name,start,peak,end,state,color,icon}`。
- **行高自适应**：`ROW_H, REGION_GAP` 必须保证 `总行数*ROW_H + (带数-1)*REGION_GAP ≤ H-PAD_TOP-PAD_BOT(=710)`。范本：21–22 行用 `ROW_H=30, REGION_GAP=8`，orb 半径 `r=13`，civ 名 `font-size:13`。行少则可放大。
- **光条**：`<rect>` 渐变 `span_<id>`(15%→peak 85%→10% 透明)；**球**：径向渐变 orb + 高光椭圆 + 图标，hover 放大用内层 `.orb-inner`(`transform-box:fill-box;transform-origin:center`，避免抖动)。
- **关系线 RELATIONS**：`{from,to,type:'continuation|war|influence'}`，hover 高亮。
- **事件竖线 EVENTS**：`{y,t}` 标志性年份。
- hover tooltip：图标+名+年代+state+narr 摘要+`🌍 同期：…`（`coexist()` 自动算）。点击 → `location.href='./<前缀>-deep.html#/civ/'+id`。
- 右下竖排 `.ds-fab` 圆按钮：🏁 对比表 / 🗗 总地图 / 🤖 AI。
- 顶部 `<h1>` 标题 + `.ds-kicker` + 一行范围"前X — 公元Y · 关键词"。
- **总地图**：Leaflet+OSM(无 key)，`Object.keys(CIV_MAP)` 遍历画点，颜色取 `EARLY_CIV_EXPLORER.civilizations`(=CIV_META)，popup 含 note + "进入该文明 →"。
- ⚠️ explorer 的 `REGIONS/INFO` 是 CIV_META 的**镜像**，新增文明要**两处同步**（CIV_META 给深度页，REGIONS/INFO 给时间轴）。

### B. 深度页 deep（文明页 = 教科书三段）
1. **Hero** `.civ-hero`：88px 圆形图标球(身份色) + `<h1>` 文明名(40px serif) + `.range`(time_range, mono+gold) + `.tag`(一句话副标题)。
2. **「了解这个文明」** `.aspects` 网格(auto-fit minmax140)：最多 8 张卡，**有数据才出**：📖文明叙事 / 🏛基础事实 / 💡关键发明 / 🌍文明关系 / 🗺遗址地图 / ⚠️常见误解 / ⏳崩溃过程 / 🎁今天遗产。点卡 → 底部滑出米黄卷轴文字面板。
3. **「时间线 · 事件与人物」**：按时期分组，每期 历史事件行 + 关键人物行，一一对应，点进入。
- 手机：hero 缩小(h1 30px)、aspects 两列。

### C. 深度页 deep（人物/事件页 = 放射宇宙图 renderCosmic）
- 中心大球 = 当前实体；周围卫星 = 关联。人物：朋友圈/参与事件；事件：🕰️时间线/关键人物/证据/因果。
- 点实体卫星→跳转；点章节卫星→底部卷轴文字面板。
- **字号/球径由 JS 按屏幕断点计算**(`matchMedia('(max-width:768px)')`)，手机放大；跨断点重渲染；**不要只用 CSS media 改字号**(气泡宽度不匹配会溢出)。

### D. 关系网 network
- `<canvas>` 力导向；顶部"选择国度"`.civ-pill`(每个地理带一颗) + 角色图例。
- 节点按角色着色(`ROLE_VAR`→主题变量)；点节点出右侧档案卡(含本国关联人物)。
- 维基真实画像：`WIKI_TITLE` 映射条目名抓 pageimages，失败回退 `CLASSICAL_ICON` 图标。

## 第五部分 · 数据契约（新章节就是填这些，字段照搬）

### `<前缀>_deep.js`
```js
const CIV_DEEP={}, EVENT_DEEP={}, PERSON_DEEP={};

// 1) 文明深度 (主体 + Object.assign 续写均可)
CIV_DEEP[id] = {
  pronunciation, capital_at_peak, territory_max, population_peak,
  language, writing, religion, economy,
  opening_narrative,          // 400+字，可用 \n 分段、**加粗**
  time_range,                 // 由 CIV_META 循环自动写，也可手填
  nine_inventions:[{name,year,body}],   // 用于 💡发明卡 + 总汇legacy
  collapse_chain:[ '...' ],   // 可选，用于 ⏳崩溃卡
};

// 2) 事件深度
EVENT_DEEP[id] = {
  full_title, one_liner, narrative,            // 300+字
  context_before, what_happened:[ '年·事' ],
  significance, evidence:[{artifact,what,held}],
  leads_to, misconception?, source, related_people:[ids]
};

// 3) 遗址地图 / 现代位置 / 常见误解
CIV_MAP[id]   = [{name:'中文 English', coords:[lat,lng], note}];
SITE_MODERN['遗址名'] = '今 X国·X省/市';   // siteModern() 读取
CIV_MYTHS[id] = [{myth:'❌说法', truth:'✓真相', why:'为何误解'}];

// 4) PERSON_DEEP 由 CLASSICAL_PEOPLE 自动生成 (勿手写)

// 5) 映射
CIV_PEOPLE_NAMES[id] = ['代表人物中文名', ...];   // 用 n 字段精确匹配
CIV_EVENTS[id]       = ['evt_xxx', ...];

// 6) 元信息 (驱动时间轴/章节/对比/总汇/地图色)
CIV_META = [{ id, name, color, icon, start, end, lane }, ...];
//   循环自动写入 CIV_DEEP[id].time_range
// 7) 派生: EARLY_CIV_EXPLORER(=CIV_META映射+对比维度), CHAPTERS(由CIV_META聚合),
//          FINAL_OVERVIEW(civs spans + today_legacy[{what,from,why}])
```

### `<前缀>_people.js`
```js
const CLASSICAL_PEOPLE=[
  {id, n:'中文名', e:'English', c:'地区', r:'角色', d:'生卒', b:'传记', rel:[{i:'id',t:'关系'}]},
];
// c(地区/国度,对应network筛选): china/greece/rome/persia/india/near_east/levant/...
// r(角色,决定配色与图标回退): ruler/general/thinker/religious/other
const CLASSICAL_ICON={ id:'emoji' };  // 人物头像图标，按身份
```

### 图标规范
- 文明图标 = `CIV_META[].icon`；人物 = `CLASSICAL_ICON`(回退按角色)；事件 = 主题图标。
- 🚫 **禁用 📅**(苹果渲染成"JUL 17")；事件用 🏛️⚔️⚖️🔤🌳🐺💥🔢☸️✝️ 等贴合内容的图标。

## 第六部分 · 内容标准

- **来源只用 A/B/C，禁 D**：A=博物馆/Nature/Britannica/UNESCO/大学教材；B=DK/NatGeo Kids(生动不幼稚)；C=自有课程模型；D(短视频/未标注网页/AI编造)严禁。
- 每文明：完整叙事(400+) + 9 基础字段 + 关键发明 + (可选崩溃链) + ≥3 事件 + ≥3 人物 + 遗址坐标+现代位置 + 常见误解。
- 事件 300+字、含真实馆藏证据；人物有传记+关系。
- 史实准确，有争议处注明(如"纣王暴行可能被周朝夸大，历史由胜利者书写")；客观、培养批判思维。
- 与相邻章节承接呼应（如古典波斯继承巴比伦、希腊继承迈锡尼）。
