🦉 小羽 · 四种游戏风格试玩

四种"让孩子愿意一直表达"的引擎，各做了一个小 demo。不用钥匙、点开就玩。玩的时候只问自己：哪一个会让一个真实的孩子，想多说一句？

风格① · 关系养成

🥚 养成 ＋ 📓 记得你的朋友

你越表达，伙伴越成长、越懂你。孩子为"一个会长大、会想念我的朋友"而回来。

灵感：Finch / 动物森友会 / 拓麻歌子 / 宝可梦
🥚 玩「表达养成」→
📓 另一种：记得你的朋友
风格② · 话即玩法

🪄 话变成东西

你说的话直接变成画面里的东西，说得越具体越热闹；说"我很开心"画不出来——玩着就学会写具体。

灵感：Scribblenauts 涂鸦冒险家
去玩 →
风格③ · 你来当作者

🎬 小剧场（你当导演）

选舞台、摆角色、说剧情——没有标准答案，你创造世界，小羽是入迷的观众，一直追问"然后呢"。

灵感：模拟人生 / Toca Boca / 我的世界
去玩 →
风格④ · 好奇探索

🗺️ 记忆小岛

一座小岛，山顶、海边、星空台……哪个在闪点哪个，小羽抛一个勾人的问题。自己选路，好奇心带着走。

灵感：塞尔达旷野之息 / 光·遇 / Journey
去玩 →
